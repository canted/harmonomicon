# Candidate 0.5 conformance

Run `python3 format/0.5/check.py` from the repository root. The 18 JSON cases include the 15 carried-forward activity traces and three `project_cycle@1` cases for team and group progress, comments, final submissions, reviews, missed work, privacy, retries, deadlines, and explicit unsupported requirements. The [two-host trial](../../../validation/0.5/README.md) imports the example packages and runs the same traces through independent local hosts, plus worker, concurrency, restart, and package-exchange probes.

The project-cycle procedure is defined by the [0.5 format document](../README.md); it is a proposed all-in-one digital activity, not an assertion that the researched game jams use this precise procedure.
