# Candidate 0.23 capabilities and limitations

The demonstrated addition is a generic typed pool with independently chosen accepted kinds and per-person limits, feeding typed iteration, qualified voting and one-source linked response. Six original compositions supplement 34 retained examples. Earlier loops and source-response instructions already reused submitted content; the narrower gap was typed multi-item collection and compatible identity-preserving consumers.

## Demonstrated capabilities

- One immutable typed pool accepts text, image, audio or mixed material, with a shared limit of 1–8 per actor. Stable unique item IDs, commit order, real author/round and quota history survive actor withdrawal/readdition, retries and restart.
- Typed iteration freezes eligible items and source-effective readers, grants only the non-self claiming reader before explicit attributed reveal, and preserves private material when unclaimed or acknowledgment times out. Empty/no-reader cases create no invented publication.
- Each eligible item can be a separate qualified vote candidate. Optional changes count one current ballot; aggregate presentation does not disclose private individual votes. Structured most-votes/tie/empty/no-vote policies and qualified selected inputs retain 0.22 guarantees.
- One-source assignments and independent immutable responses accept the same typed family. The deterministic multi-item policy selects the next non-self author and earliest item; seeded assignment samples eligible items. Explicit linked reveal publishes used source/response pairs, preserving unused private material.
- Both semantic validators reject invalid source kinds/references/scopes and missing capability declarations before execution. Both durable hosts negotiate each new operation/policy separately before target state exists.
- Actual immutable PNG/WAV uploads, owner/readiness checks and projection-based read grants pass in both authenticated SQLite hosts. Every-event restart, concurrent quota/ID/close actions and identical package transfer pass. A materially different typed response/private-pairs workshop uses package data without activity-name dispatch.
- 108 traces, 324 invalid definitions and 40 schema-valid examples pass. All 73 retained historical 0.22 traces preserve exact complete state/results/views in actual historical interpreter comparisons. See [evidence](../../validation/0.23/EVIDENCE.md).

## Bounds and host responsibilities

At most 100 effective actors, eight items per actor, 800 eligible loop items, 256 bound identities, 32 steps per sequence and 64 declared IDs. Historical withdrawn items remain in private ledger/history within bounded identities and quota accounting. Conservative resolved-date budgets include full possible loop expansion and future host actors. Null closing has no reserved interval and late deadlines retain safe-integer capping.

The host authenticates/enrolls actors, supplies trusted time/resolved dates, creates UUID instance identities, attests origins/eligibility/all-viewer access, retains durable media/state and renders text/images/audio/results. It chooses successor launch timing. The reference profile resolves sources inside one SQLite store; cross-provider trust/transfer, retention/deletion, grant administration, notifications/attention, accounts and interface design require host engineering. Read access never confers submission ownership.

## Material limits

No video, arbitrary type registry, moderation/replacement, unlimited streams, product-specific thread lifecycle, result-derived previous-winner exclusion, designated-person tie timeout, balanced/two-offer distribution, unassigned responses, executable templates or universal calendar/role/workflow engine. New consumers accept only the documented typed source family; old untyped pool consumers remain separate. Arbitrary forms and linked responses are not vote candidates. Item body outputs remain local. Multiple pool entries do not increase response quota or establish exposure fairness.

Private ballots and sources are access rules, not universal anonymity. Public attribution/counts and external information may disclose participation. Local serial SQLite trials do not establish distributed ordering, performance/load, arbitrary storage-failure robustness or production security. PNG/WAV are reference upload profiles, not language encoding restrictions. Authoring review is technical clarity review, not nontechnical usability research.

Six exact historical migrations remain complete and fourteen incomplete. Useful creative support and simpler workshop witnesses are not faithful product migration.
