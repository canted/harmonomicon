# Logo assets

The README currently uses [harmonomicon-logo.svg](harmonomicon-logo.svg). The comparison variants keep the same wordmark and circle placement:

- [harmonomicon-logo-thick.svg](harmonomicon-logo-thick.svg): two-pixel outlines on both rings.
- [harmonomicon-logo-large-ring-thick.svg](harmonomicon-logo-large-ring-thick.svg): two-pixel blue outline and one-pixel purple outline.
- [harmonomicon-logo-light-blue-fill.svg](harmonomicon-logo-light-blue-fill.svg): one-pixel outlines with the large circle filled in `#73c8ff`, sampled from the earlier dark-background wordmark.
- [harmonomicon-logo-solid-circles.svg](harmonomicon-logo-solid-circles.svg): solid dark blue and dark purple circles.
- [harmonomicon-logo-pastel-gradient.svg](harmonomicon-logo-pastel-gradient.svg): one-pixel outlines with a stepped fill of pale blue, cyan, periwinkle, and lavender.
- [harmonomicon-logo-large-grid.svg](harmonomicon-logo-large-grid.svg): approximately 40% larger artwork, with the letters and circles redrawn on the original-sized pixel grid.

The self-contained wordmark uses [Jacquard 12](https://fonts.google.com/specimen/Jacquard+12); no font file or remote asset is needed to render it. The artwork uses a pure white background with dark blue and purple lettering.

The mark above the wordmark is a pixel adaptation of [*Harmonia symbol (fixed width)*](https://commons.wikimedia.org/wiki/File:Harmonia_symbol_(fixed_width).svg) by [Kwamikagami](https://commons.wikimedia.org/wiki/User:Kwamikagami), after J. S. Stenzel. The symbol was redrawn on a pixel grid, colored, and placed above the lettering. All logo assets are licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
