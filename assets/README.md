# Logo asset

The project README uses [harmonomicon-logo.svg](harmonomicon-logo.svg). The self-contained wordmark uses [Jacquard 12](https://fonts.google.com/specimen/Jacquard+12); no font file or remote asset is needed to render it. The artwork uses a pure white background with dark blue and purple lettering.

The mark above the wordmark is a pixel adaptation of [*Harmonia symbol (fixed width)*](https://commons.wikimedia.org/wiki/File:Harmonia_symbol_(fixed_width).svg) by [Kwamikagami](https://commons.wikimedia.org/wiki/User:Kwamikagami), after J. S. Stenzel. The symbol was redrawn on a pixel grid, colored, and placed above the lettering. The logo is licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
